Installation
------------

This package is not yet distributed through any package managers.
For now, if you want to use it please manually clone the repository and install the project using PIP or any other compatible tool. We recommend always creating a dedicated virtual environment to install dependencies.

For example, you could install the tool as shown below.

.. code-block:: bash

   git clone https://github.com/molinfo-vienna/GLORYxR
   pip install ./GLORYXR
