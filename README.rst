Description
***********

GLORYxR is a tool for predicting metabolites resulting from phase 1 and phase 2 biotransformations of small molecules. It makes use of the FAME3R model family for site of metabolism (*SOM*) prediction, as well as an extensive set of purpose-built rules for metabolite enumeration.

Documentation
*************

The documentation, including installation instructions, tutorials for using the software, and full Python API documentation can be found online on `GitHub Pages <https://molinfo-vienna.github.io/GLORYxR/master/html/>`_.
